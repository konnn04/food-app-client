## 📖 Giới thiệu

Dự án **food-app-client** là ứng dụng web đặt đồ ăn trực tuyến được xây dựng bằng React và Vite. Ứng dụng hỗ trợ đa vai trò người dùng (khách hàng, nhân viên nhà hàng, quản lý) với giao diện thân thiện trên cả thiết bị di động và máy tính.

## 📂 Cấu trúc

```
food-app-client/
├── public/             # Static assets
├── src/
│   ├── assets/         # Images, fonts, etc.
│   ├── components/     # Reusable UI components
│   │   ├── layout/     # Layout components
│   │   └── ui/         # Basic UI elements
│   ├── hooks/          # Custom React hooks
│   ├── pages/          # Page components
│   │   ├── auth/       # Authentication pages
│   │   ├── home/       # Home pages
│   │   ├── orders/     # Order management
│   │   ├── payment/    # Payment pages
│   │   ├── profile/    # User profile
│   │   ├── restaurant/ # Restaurant pages
│   │   └── staff/      # Staff management pages
│   ├── services/       # API service functions
│   └── utils/          # Utility functions
├── .github/            # GitHub workflows and templates
├── vite.config.ts      # Vite configuration
└── vercel.json         # Vercel deployment config
```

## 🚀 Triển khai
Để triển khai dự án, bạn có thể sử dụng các lệnh sau:

```bash
# Cài đặt các phụ thuộc
npm install 
# Chạy ứng dụng ở môi trường phát triển
npm run dev
# Build ứng dụng cho production
npm run build
# Chạy tests
npm run test
# Xem trước phiên bản production
npm run preview
```
